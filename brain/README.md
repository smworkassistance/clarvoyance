# Brain folder

This folder is the project's working memory for the CEO research brain. Its rules are in `docs/personas/ceo-brain.md`.

| Path | What it holds | Who writes it |
|------|---------------|---------------|
| `project-brain.md` | This project's facts, vision, mission, success measures | Vision and mission: owner only. Facts: brain, with the owner's agreement. |
| `owner-model.md` | What the brain has learned about the owner, with confidence and evidence | Brain (proposes), owner (corrects) |
| `decisions.md` | Settled decisions and the owner's words | Brain, only after the owner confirms in chat |
| `backlog.md` | All ideas, sub-projects, and tasks, with status | Brain (adds), owner (decides status) |
| `inbox/questions.md` | Questions for the owner, and their answers | Brain (asks), owner (answers in chat) |
| `briefs/` | One brief per daily pass | Brain only |
| `proposals/` | Self-improvement and new-tool proposals, waiting for approval | Brain only |
| `prompts/daily-pass.md` | Instructions the scheduled run reads | Owner-approved edits only |
| `logs/` | Output log of each scheduled run | Scheduler script only |
| `Open CEO Brain.bat` | Double-click to open the page (refreshes it and starts the saving service) | Owner |
| `dashboard.html` | The page: notifications, schedule, quota, vision and mission editor, research button | Generated by `build-dashboard.ps1` |
| `history/` | Backups made before every owner edit from the page | Saving service only |
| `research/` | One file per research round | Brain (owner-triggered only) |

Full schema for every future project: `docs/personas/brain-schema.md`.

Rules:
- The brain never implements anything in `proposals/` or `backlog.md` on its own.
- The brain never edits the owner's vision or mission.
- Keep this folder tidy: close or park items each week (see `ceo-brain.md` section 7).
