# CLAR — Clarvoyance App

## What is CLAR
Personal web app built by Videh to maintain highest feeling/vibration place.
Core belief: Feeling shift karo → Life shift hogi.
Built for personal use first, general public ke liye free release planned.

## Core Philosophy
- Hum sab ultimate consciousness se bane hain (God / Source / Vortex)
- Jab sad/frustrated/depressed = consciousness se "pinch off"
- Jab happy/hopeful/content = consciousness ke highest peak pe
- Task = Feel better. Baaki sab automatically follow karta hai.
- Knowing-Doing gap solve karna = is app ka purpose
